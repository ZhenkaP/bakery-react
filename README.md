# 🥐 Сладкая Булочка — Сайт пекарни

Современный, быстрый и адаптивный сайт для пекарни, разработанный на React + Vite. Проект демонстрирует навыки создания SPA-приложений, работы с ленивой загрузкой контента и оптимизации производительности.

## ✨ Ключевые особенности

- **Code Splitting & Lazy Loading**: Компоненты карты и формы заказа загружаются только при скролле (`IntersectionObserver`), что ускоряет первоначальную загрузку.
- **Оптимизация изображений**: Hero-изображение конвертировано в WebP (~120 KB), используется `fetchPriority="high"` для LCP.
- **Адаптивный дизайн**: Mobile-first подход на Tailwind CSS, корректное отображение от 320px до 4K.
- **Чистая архитектура**: Разделение логики и представления, переиспользуемые компоненты.
- **Доступность (a11y)**: Семантическая верстка, aria-атрибуты, навигация с клавиатуры.

## 🛠 Технологический стек

- **Frontend**: React 19, Vite 8
- **Стили**: Tailwind CSS
- **Карты**: Yandex Maps API (виджет)
- **Инструменты**: ESLint, Prettier, Git

## 📦 Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ZhenkaP/bakery-react.git
   cd bakery-react
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите dev-сервер:
   ```bash
   npm run dev
   ```

4. Создайте production-сборку:
   ```bash
   npm run build
   npm run preview
   ```
